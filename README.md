# 🤖 Персональний помічник (Personal Assistant)

Консольний застосунок для керування **контактами** та **нотатками** з інтерфейсом командного рядка (CLI). Фінальний командний проєкт курсу *Python Programming: Foundations and Best Practices* (GoIT Neoversity).

Усі дані зберігаються на диску, тож помічник **не втрачає інформацію** після перезапуску.

---

## 📋 Можливості

### 📇 Контакти
- Додавання контактів з **іменем, телефонами, адресою, email та днем народження**.
- **Валідація** номера телефону (10 цифр), email та дати народження.
- **Пошук** контактів за іменем, телефоном, email або адресою (частковий збіг).
- **Редагування** та **видалення** контактів і окремих полів.
- Вивід контактів, у яких **день народження через задану кількість днів** від сьогодні.

### 📝 Нотатки
- Додавання нотаток із заголовком, текстом і тегами.
- **Пошук** за заголовком, текстом або тегом.
- **Редагування** заголовка й тексту, **видалення** нотаток.

### 💾 Зберігання даних
- Дані зберігаються в домашній папці користувача: `~/.personal_assistant/`.
- Серіалізація через `pickle` — застосунок можна перезапускати без втрати даних.

### ⭐ Додатково
- **Теги** для нотаток: додавання, видалення, пошук за тегом.
- **Кольоровий вивід** у CLI (зелений — успіх, червоний — помилка).

## 🛠 Технології
- **Python 3.10+**
- Стандартна бібліотека: `collections`, `datetime`, `pickle`, `pathlib`, `re`, `itertools`
- `colorama` — **необов'язкова** залежність для кольорового виводу (без неї застосунок працює звичайним текстом)

## 📁 Структура проєкту

## 🚀 Встановлення та запуск

```bash
# 1. Клонувати репозиторій
git clone https://github.com/NazarHook/goit-project-python-5.git
cd goit-project-python-5

# 2. Створити та активувати віртуальне середовище
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Встановити залежності (опційно — для кольорового виводу)
pip install -r requirements.txt

# 4. Запустити помічника
python main.py
```

## 💻 Команди

Після запуску введіть `help`, щоб побачити повний список.

### Контакти
| Команда | Опис |
|---|---|
| `add-contact <name> <phone>` | Додати контакт або телефон до наявного |
| `change-phone <name> <old> <new>` | Змінити номер телефону |
| `remove-phone <name> <phone>` | Видалити номер телефону |
| `phone <name>` | Показати телефони контакту |
| `add-email <name> <email>` | Додати email |
| `edit-email <name> <new_email>` | Змінити email |
| `add-address <name> <address...>` | Додати адресу |
| `add-birthday <name> <DD.MM.YYYY>` | Додати день народження |
| `edit-birthday <name> <DD.MM.YYYY>` | Змінити день народження |
| `show-birthday <name>` | Показати день народження |
| `birthdays [days]` | Дні народження на N днів уперед (типово 7) |
| `search-contact <query>` | Пошук за іменем, телефоном, email чи адресою |
| `delete-contact <name>` | Видалити контакт |
| `all-contacts` | Показати всі контакти |

### Нотатки
| Команда | Опис |
|---|---|
| `add-note <title> [\| <text>] [#tag ...]` | Додати нотатку з текстом і тегами |
| `edit-note <id> <new text...>` | Змінити текст нотатки |
| `edit-title <id> <new title...>` | Змінити заголовок |
| `add-tag <id> <tag>` | Додати тег |
| `remove-tag <id> <tag>` | Видалити тег |
| `find-note <keyword>` | Пошук за заголовком або текстом |
| `search-notes-tag <tag>` | Пошук за тегом |
| `delete-note <id>` | Видалити нотатку |
| `all-notes` | Показати всі нотатки |

### Загальні
| Команда | Опис |
|---|---|
| `hello` | Привітання |
| `help` | Список усіх команд |
| `close` / `exit` | Вийти (дані зберігаються автоматично) |

### Приклад
```
>>> add-contact John 1234567890
>>> add-email John john@example.com
>>> add-birthday John 15.08.1990
>>> birthdays 30
>>> search-contact john
>>> add-note Buy milk | 2 litres #shopping
>>> search-notes-tag shopping
>>> exit
```

## 🤝 Робота в команді

Гілка `main` **захищена** — прямий `push` заборонено. Увесь код додається **лише через Pull Request** з рев'ю.

```bash
git checkout -b feature/назва-фічі   # створити свою гілку
# ...внести зміни...
git add .
git commit -m "Короткий опис змін"
git push -u origin feature/назва-фічі
```
Далі — відкрити **Pull Request** у `main` на GitHub, дочекатися рев'ю та схвалення.
